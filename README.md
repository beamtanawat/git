# Git HTML Starter

## Overview

This repository contains a minimal HTML and JavaScript starter project.

## Contents

- `index.html` displays a minimal page labelled “git first time”.
- `scrip.js` contains a console message. The current `index.html` does not reference this script.

## How to open

Open `index.html` in a web browser.

## Status and limitations

This is a basic starter project rather than a completed application. It contains no backend, database, live integration, or documented production feature set.
